# coiltrace

Coil CSV/TSV trace tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/coiltrace/

## Install / run

```bash
git clone https://github.com/theworker02/coiltrace.git
cd coiltrace
node src/cli.js
node --test
```
